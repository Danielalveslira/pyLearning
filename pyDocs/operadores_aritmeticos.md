# Operators in Python

In Python, just like in many other programming languages, we have arithmetic operators:

- `+`
- `-`
- `*`
- `/`
- `**`
- `//`
- `%`

## Examples

```py
5 + 2   # 7
5 - 2   # 3
5 * 2   # 10
5 / 2   # 2.5
5 ** 2  # 25
5 // 2  # 2
5 % 2   # 1
```
## What each operator does
- `+` Addition
- `-` Subtraction
- `*` Multiplication
- `/` Division
- `**` Exponentiation
- `//` Integer division
- `%` Remainder of division

`=` and `==`

Using two equal signs, `==`, is for comparison. It checks if one value is equal to another.

A single equal sign, `=`, is used for assignment.

## Example
```py
x = 5 # assignment
x == 5 # comparison
```
## Order of precedence
Python follows an order when evaluating expressions:

1. `()` Parentheses
2. `**`
3. `*`, `/`, `//`, `%`
4. `+`, `-`

## Example
```py
2 + 2 * 4 # 14 🤯⁉️
(2 + 3) * 4 # 20 😌🤝
```
